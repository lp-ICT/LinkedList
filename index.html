甚麼是
鏈表 Linked List？

鏈表由多個節點 Node組成。每個節點保存一項數據 Data，以及指向下一個節點記憶體位址的指示標 Pointer。節點不用連續存放，仍可依次找到。

節點 Node = 數據 Data + 指示標 Pointer
最後節點的 Pointer 是 NULL

邏輯次序靠指示標 Pointer 連接

104、720、308並不連續。電腦依靠每個 Pointer 內的位址，仍能按照 A → B → C 的次序讀取所有數據。

一分鐘溫習

  • HEAD：保存第一個節點 Node 的位址；空鏈表時為 NULL。
  • 插入：建立新節點 Node，並修改相關的指示標 Pointer。
  • 刪除：讓前一節點的 Pointer 跳過被刪節點，改指向其後一節點。
  • Traversal：從 HEAD 開始，沿每個 Pointer 逐一讀取數據 Data。
結構儲存及存取特點
陣列 Array元素通常連續存放，可用索引直接存取
鏈表 Linked List節點 Node 不用連續存放，須沿 Pointer 逐個尋找
